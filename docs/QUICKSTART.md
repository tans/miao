# MIAO 快速开始

> 当前版本正在恢复用户工作台和管理入口。下列应用、表格、成员、用量和日志操作描述目标使用流程；在对应工作台阶段完成之前，部分功能尚不能从当前主界面进入。现阶段以应用中的实际可见入口为准，API 与运行维护能力见[API 参考](API.md)和[部署配置](DEPLOYMENT.md)。平台后台及用户工作台按[产品方案](ADMIN_AND_WORKBENCH_PLAN.md)分阶段交付。

## 注册并创建应用

1. 打开 MIAO，使用邮箱注册并登录。注册策略由管理员设置；启用邮箱验证时，先打开邮件中的验证链接。
2. 工作台中选择“创建应用”，填写名称和用途说明。MIAO 提供轻量数据应用，不会根据描述自动生成完整业务页面或流程。
3. 打开应用后，新建数据表并添加字段。字段支持文本、数字、是/否、日期、邮箱、网址、选项、关联记录和附件；可设置必填项。
4. 添加、编辑、搜索和筛选记录。通过表头的字段设置可以调整标签、必填状态、选项和字段集合。

## fx AI 助手

浏览器需要支持 WebAssembly JSPI，且管理员需要配置 AI Gateway。否则仍可用数据表界面手动建表和维护记录。fx 只能访问当前登录用户当前工作区和应用有权访问的数据。

## 邀请和权限

工作区所有者可邀请同事、停用/移除成员，以及设置管理员角色。管理员可协助管理成员。所有者还可以限制某个应用的访问对象，并分别授予只读或编辑权限；未限制的应用沿用工作区成员的编辑权限。

## 数据安全

确认删除应用会同时永久删除其中的数据表和记录。归档会把应用从常用列表移入“已归档”，之后可恢复。删除字段会永久清除该字段的数据，并要求再次确认。

“导出数据”会下载当前工作区的 JSON 文件，包含应用、表结构和记录。操作日志由工作区所有者查看。

管理员应配置自动备份并定期在隔离的 PocketBase 实例演练恢复。参见[备份与恢复手册](BACKUP.md)和[部署配置](DEPLOYMENT.md)。
