# MIAO 快速开始

> 登录后默认进入应用工作台。平台后台只对 `MIAO_ADMIN_EMAILS` 配置的管理员显示；平台支持界面只展示账号、工作区和应用元数据及汇总用量。目标环境的账号权限、邮件、AI 和备份恢复验收仍需由部署方完成。完整范围见[平台后台与用户工作台方案](ADMIN_AND_WORKBENCH_PLAN.md)。

## 注册并创建应用

1. 打开 MIAO，使用邮箱注册并登录。注册策略由管理员设置；启用邮箱验证时，先打开邮件中的验证链接。登录后默认进入工作台首页。
2. 选择当前工作区，打开已有应用或选择“创建应用”，填写名称和用途说明。MIAO 提供轻量数据应用，不会根据描述自动生成完整业务页面或流程。
3. 打开应用后，新建数据表并添加字段。字段支持文本、数字、是/否、日期、邮箱、网址、选项、关联记录和附件；可设置必填项。
4. 添加、编辑、搜索和筛选记录。通过表头的字段设置可以调整标签、必填状态、选项和字段集合。

## fx AI 助手

从工作台左侧选择“fx 助手”进入独立对话页。浏览器需要支持 WebAssembly JSPI，且管理员需要配置 AI Gateway。否则仍可用应用页手动建表和维护记录。fx 只能访问当前登录用户当前工作区和应用有权访问的数据。切换工作区会清空当前对话上下文。

## 邀请和权限

工作区成员可查看成员名单；所有者和管理员可邀请、查看和撤销邀请，只有所有者可以调整角色或移除成员。移除只影响当前工作区。所有者还可以限制某个应用的访问对象，并分别授予只读或编辑权限；未限制的应用沿用工作区成员的编辑权限。全局账号停用与恢复由平台后台管理员处理。

## 数据安全

确认删除应用会同时永久删除其中的数据表和记录。归档会把应用从常用列表移入“已归档”，之后可恢复。删除字段会永久清除该字段的数据，并要求再次确认。

“导出工作区数据”会下载当前工作区的 JSON 文件，包含当前用户有权访问的应用、表结构和记录。操作日志由工作区所有者分页查看。账号自助停用后不能自行恢复；需要联系平台管理员。

管理员应配置自动备份并定期在隔离的 PocketBase 实例演练恢复。参见[备份与恢复手册](BACKUP.md)和[部署配置](DEPLOYMENT.md)。
