# MIAO 当前能力与发布限制

更新日期：2026-09-29。本文对应当前仓库实现；代码具备某项能力不代表该能力已在生产环境完成演练。

## 产品定位

MIAO 是轻量数据应用，可创建应用和数据表、维护记录，并通过 fx 助手操作当前有权访问的数据。应用描述用于说明用途，不会自动生成完整业务页面或工作流。

## 已实现

- 账号注册/登录、可选邮箱验证、密码重置、注册模式和邮箱域限制，以及用户自行停用或删除账号。
- 多工作区成员与邀请；配置邮件服务后可投递验证、重置和邀请邮件，否则邀请可复制链接发送。
- 工作区 owner/admin/member 角色，以及 owner 配置的应用级 viewer/editor 权限。
- 应用创建、编辑、归档/恢复和确认后永久删除；数据表改名、字段标签/必填/选项调整、字段增删和确认后删除。
- 记录类型化新增、编辑、删除、分页、文本搜索、排序和单字段筛选；字段支持文本、数字、日期、布尔、邮箱、网址、选项、同应用关联和附件。
- 平台管理员在界面配置/轮换加密保存的 AI Gateway key；工作区每日请求预算和持久化请求/token 用量查看。
- PocketBase 备份/恢复脚本、操作日志、当前用户可访问应用的数据 JSON 导出，以及快速开始、API、部署和备份恢复文档。

## 已知限制与上线要求

- 需要真实 Gateway 凭据才能验收模型交互；JSPI 不可用时提供手动建表和维护记录的路径。
- 每用户/工作区/平台请求限制和每日预算按请求计数，不等同于供应商费用上限。流式 token 解析可能受 Gateway 响应格式影响，需对账。
- 结构字段类型和关联目标不能原地更换；复杂多值关系、选项和文件过滤暂不支持。附件上限 5 MB，JSON 导出不包含附件二进制；PocketBase 备份包含附件文件。
- 操作日志记录成功写请求的路由、操作者、状态和目标标识，不保存业务字段值。日志和导出面向当前工作区；受限应用仅对获授权用户导出。
- PocketBase 备份需由运营方配置定时任务和异地复制，并在隔离环境定期演练恢复。恢复会替换实例数据。
- 邮件投递依赖 Resend 配置；还需在目标部署环境验证发件域、邮件到达及公网回调链接。
- 生产发布前仍需在目标环境验收登录/邮件、真实 AI 对话、跨工作区和应用权限、附件、备份恢复及反向代理流程。`miao-test` 的历史 API 自动化结果记录在该项目的 `docs/coverage.md`，不覆盖这些页面交互及运维检查；本次收尾未运行测试。
